# Short 001 — "Same Gray"

A finished 27.4 s vertical Short proving two identically-coloured squares look
different, because the brain compares each patch to its surroundings instead of
measuring light.

Everything here is original: the illusion plate, the icons, the narration, the
music bed and every sound effect are generated by the scripts in `render/`.
No stock footage, no third-party audio, no screenshots.

## 2. The science on screen (and the numbers behind it)

Both patches are filled with the identical value `#7F7F7F`. Only the surround
changes:

| | patch (source) | patch (decoded from the MP4) | surround 200 px above/below |
|---|---|---|---|
| top square | `#7F7F7F` (127) | **126,126,126** | **#24 → #59** (36 → 89) |
| bottom square | `#7F7F7F` (127) | **126,126,126** | **#91 → #C0** (145 → 192) |

The ~1 LSB offset is normal 8-bit YUV round-trip, and it is **identical on both
patches**, so the illusion survives compression exactly as intended.

**Proof 1 — mask.** `mask_windows.png` covers everything except two windows the
exact size of the squares. Measured inside both windows in the finished video:
`127,127,127` and `127,127,127`. Same colour, no surround.

**Proof 2 — connect.** A `#7F7F7F` bar slides in from under the mask and welds
the two squares into one continuous shape. The cyan outline traces the union,
so the "two colours" collapse into a single object in front of the viewer.

**Fix applied to the original blueprint:** the caption said "dark around →
looks lighter". The patch *on the dark surround* is the one that looks lighter,
so the on-screen copy now reads **"DARKER AROUND / LOOKS LIGHTER"** — correct,
and still four words per card.

## 4. Loop engineering

The final 9 frames are not animated — the renderer returns the untouched source
plate from 27.09 s onward. Measured on the encoded file, first frame vs last
frame: **max channel difference 6/255, mean 0.28, zero pixels differing by more
than 8** (pure encoder noise). The viewer lands back on the opening image with
the squares looking different again.

## 5. Sound design

Original, generated with `render/synth.py` (no samples, no licence to clear):

- **Bed** — 120 BPM, Am–F–C–G pad + sub bass, side-chain ducked −9 dB under the
  voice, sitting ~18 dB below it.
- **SFX** — whoosh, UI ticks, riser, shutter, thud, pops, snare, wipe swish,
  slide-lock, two dings and a final chord, all placed on narration cues.
- **Hooks muted by design** — drums drop out for 0.85 s at the reveal, and the
  bed hard-cuts at 27.09 s so the loop has no tail.

## 6. Rebuild

```bash
pip install -r requirements.txt
./build.sh          # ~2 min end to end
```

Individual stages:

```bash
cd render
python3 assets.py                 # illusion plate, mask, bar, icons
python3 timeline.py               # trims/normalises VO, emits cues.json
python3 audio.py                  # music, SFX, −14 LUFS mix
python3 render.py                 # 822 frames -> video/same-gray-short.mp4
python3 render.py stills 6.8 21.5 # preview single frames
python3 thumb.py                  # poster frame
```

Every visual cue is read from `render/cues.json`, which `timeline.py` derives
from the actual narration audio — so if you re-record the voice, re-run
`timeline.py` and the whole edit re-times itself.

### Editing geometry

`render/common.py` holds the layout. If you widen the gap between the squares,
keep the gradient anchors in step or the illusion weakens:

```python
SQ_TOP_CY, SQ_BOT_CY = 470, 1010     # square centres
GRAD_ANCHORS = [(0.000, 18), (0.245, 48), (0.526, 186), (1.000, 242)]
```

The plate also carries a static ±1 LSB dither in the gradient (never on the
patches) — that is what stops the ramp from banding after H.264.
